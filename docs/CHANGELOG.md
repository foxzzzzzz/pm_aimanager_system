# 变更记录与里程碑

## 2026-08-07

### Phase 3.1 修复与优化

- 管理端取消可伪造的 `X-Actor-Id`，改为运行时Bearer令牌和服务端管理员身份映射。
- 修复旧基线提案误批准、历史Excel假发布、冲突状态回滚、倒置日期和仅重新保存文件产生伪差异的问题。
- 项目版本发布与提案审批增加项目行锁、基线和目标字段校验；发布团队变更时自动撤销离组成员权限。
- 手机号改为服务端密钥HMAC和掩码存储；限制同一用户在同一项目只能绑定一个成员身份。
- 补齐管理端成员邀请，以及小程序A角审批、问题状态更新和消息已读闭环。
- OpenAI兼容客户端接入外部重试与结构化输出模式配置，支持严格Schema失败后降级JSON模式，并在发送前脱敏手机号。
- 增加 `0004_phase31` 迁移和前后端行为测试；迁移既有版本为业务快照哈希，并修复PostgreSQL与SQLite的手机号掩码SQL差异。升级时会安全撤销无法无损转换的未完成旧邀请，项目经理可重新生成。
